相对 v0 的改动

  • 一个会话同一时刻只显示一种状态：按下方「状态优先级」取最高的一种。已结束的会话不再同时显示弹窗、离线横幅和模型 chip，输入框换成一张状态卡
  • 要你处理的东西停靠在输入框上方：审批、模型提问、计划、终端弹窗不再是聊天流里的卡片，不会被新消息顶走；处理完在聊天里留一行记录
  • 主页直接列出进行中的会话：从主页到正在跑的会话只要点一下；「需要处理」改为竖排，审批可以在主页直接允许或拒绝；项目列表放到下面，只做历史入口
  • 新建会话只有一个入口：去掉项目行上的 ＋；主页右上角和项目页右下角各一个，项目页里的会预填项目。新建面板第一行是项目，显示实际会用的模型和目录，不再写「默认」
  • 项目页不用分段：进行中和最近结束上下排，进行中为空时不再只剩一句「没有进行中的会话」
  • 会话标题不再统一叫「新会话」：没有标题时用第一句话，还没发过话就用「目录名 · 时间」
  • 聊天正文按 Markdown 排版：列表、代码块、标题正常显示；文件引用显示成等宽灰字，不用蓝色（点不开的东西不像链接）；连续的已完成工具调用折叠成一行
  • 终端的错误和断线换成一张居中的状态卡，给出中文说明和「重新连接」按钮
  • 宽屏侧栏和手机主页结构一致：需要处理、进行中、项目；项目可以展开看最近结束的会话；去掉 0 计数。没选会话时主区域是新建会话的输入框，不再是空白
  • 底部标签「项目」改名「会话」，和主页内容一致；上下文超过 80% 时由上下文 chip 变橙并带「压缩」，不再另起一条横幅
  • 触控尺寸：返回、更多、按键栏等可点区域不小于 44×44；底部标签「项目」上显示待处理数
  • 新增暗色稿；设置页在推送没开时给出提醒

状态优先级

列表的圆点和预览、导航栏的圆点、会话底部的停靠区或状态卡，都只取优先级最高的一种。

优先级状态圆点列表预览会话底部
1已结束灰最后一条回复状态卡「会话已结束」+ 恢复（电脑在线时）
2电脑离线灰「电脑不在线」状态卡「××× 不在线」
3等待审批橙「请求执行 …」停靠区：审批
4模型提问橙「Codex 在问你」停靠区：选项
5计划待批准橙「计划待批准」停靠区：计划
6终端弹窗橙「终端里有弹窗」停靠区：去终端
7运行中 / 启动中蓝当前的工具或最后一句输入框 + 中断
8空闲绿最后一条回复输入框

会话标题

  • 有标题用标题；没有就用第一句用户消息，截到一行；还没发过话用「目录名 · 开始时间」，如「billing · 11:25」

一行预览

  • 去掉所有 Markdown 标记后再截断，截断处不留半个链接或代码标记
