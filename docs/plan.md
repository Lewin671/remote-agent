## 下一步

按顺序做；前两项不依赖其他工作。

1. **真机验收**。在自己的 Android 手机和 iPhone（PWA）上走一遍，清单在「待确认 › 真机」。验收标准：清单里每一项有结论，问题修掉或记进本文
2. **Codex 0.159.2 的命令结果**。按新格式解析退出码或失败，再把 0.159.2 列为已验证版本。验收标准：失败的命令在客户端显示 ✕ 和退出码，`remote-agent doctor` 通过
3. **定时任务的客户端**。客户端通过 `MachineCapabilities.scheduled_tasks` 判断支持情况，复用 Schedule 机器指令查询和管理任务；先定变更订阅和离线快照，再出界面稿，然后做全局任务页和会话内入口。设计见 [architecture §18](architecture.md#18-定时任务)
4. **历史分段读取**。现在事件层从序号 1 读全量，长会话第一次打开慢（瓶颈是下载量，见 [architecture §10](architecture.md#10-报文同步和指令) 的「后台和内存」）；网页再次打开已经靠本地密文缓存只取增量。剩下的是第一次打开：先取最新一段显示，更早的在后台补，需要让状态推导不依赖从序号 1 开始的完整历史。网页和 Android 都要做
5. **v8 以后的界面改动补验收**。两端逐屏对照 client-v29（网页的 v8 改动也没有逐屏对照过），并连真实 CLI 走一遍设置类页面

**Android 的小缺口**（没排期，碰到相关改动时一起做）：

- 带方向标记的原图以最高画质重新编码，不是无损旋转（网页已是无损），界面上有注明
- API 26 到 28 上保存图片要请求存储权限，还没做
- 大图过期、校验失败这两种状态没有在真实数据上看过
- 设备列表、客户端详情、添加设备和开源许可页在平板上没有限制列宽
- 终端输出积压后断开重连，没有用真实的大量输出触发过

**网页的小缺口**：终端自动按宽度缩放字号，没有 Android 那样的 A− / A+。

## 待确认

所有还没定的问题和待实测的行为都列在这里，有了结论就写进对应的文档，再从这里删掉。

**真机**

- Android：终端里系统字体的中文、回退的符号和 emoji 显示；字号调节、键盘弹出和旋转；中文输入法在终端里输入、在输入框里多行输入；终端方向键；设了锁屏时通知里的「允许」「拒绝」要先解锁；FCM 在国内网络和省电策略下的到达；连续使用一天没有 ANR 和崩溃（模拟器上只验证了英文输入和没有锁屏的情况，见 [android-notes.md](android-notes.md)）
- 网页：终端视图的按键栏、键盘弹出、系统选图和分享面板、推送（iPhone 要先添加到主屏幕）、扫码配对，都只在本机 Chrome 上验证过

**范围和产品**

- 额度页的「重新读取」和「API 计费」状态在界面稿和 [architecture · 账户额度](architecture.md#账户额度) 里有，网页和 Android 都还没有实现；做不做、何时做未定
- Android 的会话和项目页在平板与横屏上仍是手机布局，要不要做网页那样的侧栏加主区域未定
- 客户端切换 fast 模式是否要做（优先级低）
- 运行中的会话要不要也能分叉（比如主任务跑着，另开一支问别的）。现在只允许空闲和已结束的会话（[architecture §13](architecture.md#13-daemon-设置与远程新建会话)）；要做得先实测两个 CLI 怎么处理停在一轮中间的记录，再定复制来的历史在哪里收尾
- 会话图片的保存期限（30 天）和配额（1 GiB）、预览长边 320px、显示版 2048px、加密后整个信封不超过 1 MiB 都是初始取值（[session-images.md](session-images.md)），要用实际截图和一段时间的用量看清晰度、流量和空间再定
- server 的过期图片仍保留状态行，SQLite 空间用于后续复用；是否需要定期压缩数据库及历史元数据期限未定
- 图片过期后要不要支持从电脑重新取（daemon 从 rollout 或 transcript 里重新编码上传）；需要机器在线，也要一个新的指令
- 以后做不做原生 iOS：做的话，再比较把 `:core` 迁到 KMP 和改用 gomobile 复用 Go

**Codex 待实测**

- 0.159.2 把执行命令记成通用的 `ToolCall`（结果是 `Script completed … Output:`），没有退出码；新格式里失败怎么表示
- `auto_review` 直接拒绝时，模型是否会在对话里请求批准（目前没复现出来）
- 模型提问：多个问题时按编号是否逐题前进；`None of the above` 加备注怎么按；非 Plan 模式下模型会不会用这两个工具
- `[notice]` 下除 `hide_rate_limit_model_nudge` 以外的几个开关是否有效

**Claude Code 待实测**

- `PermissionRequest` hook 能否直接返回「以后不再问」的规则（`updatedPermissions`）。能的话，永久授权就能可靠绑定到具体请求，[architecture §7](architecture.md#7-审批) 里「客户端只允许单次审批」的限制可以重新讨论
- auto 模式下被分类器拦下的请求会不会弹权限框、触发 `PermissionRequest`（分类器放行的不触发，已实测；拦下的情况没能复现）
- 以 bypass 启动时的风险确认弹窗（本机设置跳过了它）
- API 出错时一轮怎么结束：transcript 里有没有 `turn_duration` 或其他结束记录；没有的话会一直显示运行中
- AskUserQuestion 的选择框里按 Esc、选 `Type something.` 和 `Chat about this` 的结果

**Android 待验证**

- 平台 JCA 能否导入导出原始 32 字节的 X25519、Ed25519 密钥（现在一直用 Bouncy Castle）
