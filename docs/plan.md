### 直连实施与验收

以下是独立的依赖顺序：**第 0 → 1 → 2 → 3 → 4 期，每期 daemon + 网页 → Android → iOS**。各期可独立发布、直连随时可关闭；改变协议约定时所有端须协调升级，关闭直连不容许旧协议互通。设计以 [transport.md](transport.md) 为准，原型不算阶段完成。

| 期次 | 下一步 | 验收标准（目标，尚未达成） |
|---|---|---|
| 0：RelayPath 与中继恢复 | 抽出 Link/Router/Path 和共享 dispatcher，只接 RelayPath；同时修四端中继活性、网络代次与在途 Forward 恢复 | 四端和安全测试通过，原生 CLI、历史先存后推、通知、图片保留语义不变；同环境隔离全链路 p95 无明显回归。旧连接 RST、无事件静默黑洞、同接口换 Wi-Fi/DHCP、daemon 换网均主动恢复，不能仍依赖旧 60 秒/45 秒/20–40 秒等待；具体新心跳参数须先按「待确认」定值并实测无误离线。原 ID/截止时间的重试不重复执行，旧代次不能接管新状态 |

各期同时受以下**后续验收目标**约束（采用可行性验证报告 H 的门槛，并非已测产品指标）：

- **首次调用与退路**：不等待 ICE；UDP 全丢、STUN 无响应、候选洪泛时，对照同网络纯 relay，relay p95 增量 <5 ms，探测失败不变成业务失败。
- **文件与交互隔离**：同机和千兆 LAN 的两个真实端点，至少 64 MiB 连续文件目标 ≥20 MB/s；同时每 20 ms 输入小包，交互 p95 增量 <10 ms。手机另验 CPU、内存与温度预算，不能套用 M1 双端进程数字。
- **升级价值**：中继 RTT 150 ms、直接路径 10–40 ms 的隔离对照中，交互 p95 明确降低；direct p95 持续更差则不升级。bulk 用同文件/网络独立验吞吐，不仅看 RTT。
- **切换**：小流量热备覆盖路径判定窗口；bulk 按设计默认 500 ms/RTT 自适应软预算启动备用，250 ms 只作受控配置。记录故障到备用发送、最大连续应用间隔、ACK 和最终完成时间，不把信令耗时当业务恢复，也不把有限窗口无误切当零误判保证。
- **资源与撤销**：peer/全局发送和重组有字节、数量、期限上限，持续 30 分钟传输内存不持续增长；两路撤销设备和租约过期一致生效。测试覆盖同时断路与进程崩溃，明确 unknown/快照限制。

**路径界面稿另行更新**：按 [transport · 界面规则](transport.md#7-界面规则) 出下一版完整界面稿，本任务不改 HTML。验收三端会话副标题、气泡、电脑状态行、连接检查与“尽量直连”开关，亮暗主题、辅助功能与本地化；路径切换不弹提示，关闭后无 STUN/ICE。功能实现须经隔离 server → daemon → tmux → 真实 CLI，再回客户端，分别记录直接界面操作与调试触发，不使用日常账户。

### 传输模块与直连

以下按阻塞程度排序；设计已确定的事项不在此重议。

1. **第 1 期下载接口与共享对象边界**：当前 checkout 的 proto/daemon 没有 `GetSharedFileChunk`，原型取回也不是该接口；只读分块下载范围已定，但共享对象如何产生、授权绑定账户/设备/会话、稳定文件 ID/版本/哈希、删除/过期/修改时续传、配额及电脑离线语义仍需决定。建议与 agent 发文件任务共用显式共享对象，不接受客户端任意路径；先锁定对象身份和授权，再定指令，不能把 server `GetImage` 显示副本搬走。
2. **恢复参数与资源预算**：第 0 期心跳周期、连续缺失与新连接试探期限；各用途发送/重组上限、ACK/replay 窗口大小、barrier 期限；Router 判定“不差”的样本窗/容差；单设备对 ICE 候选/速率与重试限额未定。建议用受控 RTT、3% 丢包、调度暂停和 bulk 洪泛先定有界预算；soft timeout 只触发备用，不能误报电脑离线。网页网络 API 缺失、iOS 同接口换网和 daemon 系统通知须有探测兜底。
3. **STUN 生产接入**：自建方向已定，UDP 入口/双栈、容量、防放大/限流、部署与监测参数未定；建议独立受限服务，地址仅作短期内存限流键，不进入持久日志，不依赖第三方服务。
4. **真实 NAT/运营商/IPv6 成功率与两机 LAN**：未测代表性网络对、公司 UDP 策略、双栈、真实两机局域网；2026-10 NAT 采样不能推导百分比。建议按下方手机步骤报告分层 k/n 与区间；LAN 先排除访客隔离/VPN/主机防火墙，再验双向文件与交互，不以同机回环替代。
5. **移动 WebRTC 运行与包体**：Android JNI/R8、16 KiB page size、DataChannel-only 初始化、stripped/ABI 方案及 release APK 增量；iOS SDK 注入、真机 arm64 归档/下载增量、隐私清单、本地网络权限与出口加密申报均未验证。建议同版本空壳 App 有/无依赖对照归档，确认 CPU/温度/包体后定库与 ABI，不把 ZIP 成员大小当安装大小。
6. **Safari/iOS PWA、原生后台与锁屏**：未测消息上限、真实 NIC 变化、锁屏/挂起/进程回收、Doze、前台安全同步及恢复；建议按下方步骤实测，后台不承诺实时交付、不增加伪音频/VoIP 保活。
7. **长时间能耗与内存**：未测真实手机 30 分钟上传/下载+交互、稳定空闲、后台/锁屏的电量/CPU/内存/温度与持续 ICE 重试；建议同机同网络与关闭直连的对照，先定手机资源预算及可接受探测成本。M1 双端合计 CPU/RSS 不能充作手机预算。
8. **开关的保存范围与路径显示口径**：本机 off/auto 和默认开已定；设置在电脑列表中的呈现是否按目标电脑独立保存仍需确认。建议本机按电脑保存，避免一台特殊网络的电脑影响其他电脑；检查页分用途显示，副标题按交互主路径，热备仍如实说明。

**需要用户手机配合的测量步骤（未执行）**：
