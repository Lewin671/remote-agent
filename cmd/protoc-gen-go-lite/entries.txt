# Direction-aware code generation roots for cmd/protoc-gen-go-lite.
#
# Directives (one per line, comments start with #):
#   in: <full_name>     Shell -> Core boundary; generates Unmarshal transitively.
#   out: <full_name>    Core -> Shell boundary; generates Size, AppendMarshal, Marshal transitively.
#   clone: <full_name>  Core deep-copy call sites; generates Clone transitively.
#   <full_name>         Bare entry without prefix is treated as both in + out.
#
# How to add entries:
#   - New Screen/Event/ViewModel/Effect messages wired into app.proto are
#     picked up automatically from the in:/out: roots below.
#   - If clientcore calls .Unmarshal() or .Marshal() on a new top-level or
#     byte-embedded proto type (such as remoteagent.v1.Command), add in:/out:.
#   - If clientcore calls .Clone() on a message type, compilation will fail
#     until you add `clone: <full.proto.Name>` here and regenerate.
#   - Regenerate lite Go bindings: buf generate --template buf.gen.lite.yaml
#   - Verify: cd clientcore && CC=/usr/bin/clang go test ./...
